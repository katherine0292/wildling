## 客户要求、我的方案与待确认取舍

| 主题 | [客户] 要求 | [方案] 我的方案 | [待确认] 取舍 |
|---|---|---|---|
| 交互路线 | V1 允许两条路线；V2 保留三工具并加“等待” | 工具是**请求**而不是命令；角色根据需要、压力与历史决定 | 是否在研究证明可靠后弱化工具界面 |
| 动作理解 | V2 要求训练并可评估的分类，不能只用单帧速度 | 600 ms 时序窗口、20 Hz 重采样、1D CNN + 统计基线、阈值由验证集冻结 | 20% 第二人复核的人力来源 |
| 行为模型 | V2 要求硬约束 + 效用 | 8 个候选、250 ms 决策、惯性 0.10、切换门槛 0.15、请求加成 0.25 | 参数在可用性测试后调整 |
| 信任 | 不能声称测量观众真实心理 | 主屏只显示角色状态文字；精确值仅工作人员端 | — |
| 适应 | 至少 3 次有效事件后才可见 | 三个偏好、中位数目标、0.8/0.2 平滑、10 s 限频 | — |
| 成长 | 不能靠持续按住一个动作刷取 | 单项 ≥ 0.20、stress ≤ 0.40、同工具奖励每分钟封顶 | — |
| 架构 | Processing 正式展示 + Node 唯一大脑 | 回环 WebSocket、30 Hz 快照、commandId 去重 | Processing 实际运行环境首周验证 |
| 数据 | 不保存原始视频 | 只存匿名归一化关键点；30 天删除研究副本 | 是否记录匿名研究统计 |
| 语言 | 英文主界面，中文可切换 | 文案独立配置 | 最终公开文案由客户确认 |
| 设备与场地 | 启动周确认 | 暂定 8 GB / 720p / 1920×1080 基线 | 实际设备、光照、年龄、招募、上线日期 |
