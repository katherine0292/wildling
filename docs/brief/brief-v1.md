本 brief 的任务是制作一件以野生猫科虚拟生物为主角的互动作品，让观众通过自己的动作、停留和照料，感受到一段关系如何形成。我们关注生物的自主反应、动作与反馈的因果关系，以及成长带来的情感变化。请将它作为创意编程与交互原型项目完成。

## 1 项目介绍

我们计划在一个面向公众的游戏与交互体验展示中呈现 Wildling。作品是一只俯视视角的虚拟野猫，它会探索环境、表达需要，并对观众的靠近、抚摸和快速动作作出反应。随着时间与互动，它由幼猫成长，并经历丛林、雪地和沙漠三个环境。

作品的主题是**“照料如何建立信任”**。观众既是互动参与者，也是观察者。我们希望观众意识到：相同的动作，在不同的信任程度和身体状态下，可以获得不同的回应；虚拟生物也应有自己的节奏。

项目不要求写实模拟真实猫科动物的生态。三个地貌是成长的艺术隐喻，不应作为真实野猫迁徙路线或动物护理知识对外介绍。

## 2 创意命题与体验目标

**核心命题：** 通过一个可以看见内部需要的虚拟生物，让观众理解行为、需要、信任与成长之间的关系。

| 目标 | 内容 |
|---|---|
| 可理解 | 初次接触的观众能发现至少一种有效互动，并知道自己的动作改变了什么 |
| 有生命感 | 即使观众暂时没有动作，生物仍有可观察的行为 |
| 有关系感 | 温和接触与持续追逐应带来不同的关系结果 |
| 可呈现 | 作品应能完整演示，不依赖讲解者逐帧解释程序 |

设计师应优先解决行为反馈的清晰度，再增加视觉复杂度。复杂骨骼、更多场景和更多数值不能替代可理解的互动关系。

## 3 受众与使用场景

- 主要受众：对游戏、数字艺术和互动体验感兴趣的普通观众；无需编程背景，不预设其熟悉手势识别。
- 单次体验以一位主要参与者为中心，其他人可以旁观。
- 原型环境：配有摄像头、鼠标与扬声器的电脑；浏览器全屏展示；摄像头检测一只手，鼠标提供无摄像头的等效体验。作品应可在个人电脑上独立演示。
- 真实展场的设备规格、年龄限制、多人容量或正式体验时长，应在商业委托启动时另行确认。

## 4 核心体验流程

1. 进入作品，了解 Wildling 是一只会回应动作、产生需要并成长的虚拟生物。
2. 选择摄像头或鼠标输入，完成第一次有效动作。
3. 观察动作引发的姿态、移动、声音和状态变化。
4. 根据它的需要调整互动方式，在陪伴与放手之间建立自己的节奏。
5. 观察体型、环境或关系的变化，完成一次成长体验或继续观察生命循环。

## 5 原始功能需求

### 5.1 虚拟生物与身体表达
主角应是一只可辨识的猫科生物，至少能表达移动、安静接触、玩耍或追逐、躲避和休息。耳朵、尾巴、眼睛、步态或呼吸中的至少两种表达应与当前状态相关。身体可采用简单图形组合或程序化骨骼，但行为状态与视觉姿态必须一致。状态变化不能只发生在数值面板上。

### 5.2 输入与互动
摄像头模式应将手的位置映射到交互空间，并利用运动速度和与猫的距离区分温和接触与快速靠近。鼠标模式应保持相同的基本因果关系。

基于两个版本，可识别出两条原型路线：**路线 A** 以抚摸、追逐和观察为核心，强调生物自主生活；**路线 B** 以明确的 Feed、Play、Pet 工具为核心，强调可理解的照料任务。它们是同一主题下不同的交互组织方式，不宜宣称两条路线的全部功能已同时存在。

### 5.3 需要与行为系统
生物应包含内部状态，并使状态影响选择。需求重点是这些状态形成可解释的行为关系，而非固定必须使用哪四个指标。

当精力下降时应休息；当饥饿时应获取食物或表达需要；温和相处应增加信任；快速靠近应在一定条件下引发躲避。已有信任可以改变反应，但不能把“完全服从观众”当作作品唯一结局。

### 5.4 成长与环境
作品应具有幼年、青年和成年三个主要成长段，并分别对应丛林、雪地与沙漠。成长应可见，且有过渡提示。

### 5.5 反馈与说明
界面应显示当前需要与交互状态，允许观众知道系统是否看见了手。声音应增强状态感知，且提供静音控制。简短气泡或字幕应帮助理解当前行为，不需要开放式聊天。

## 6 原始技术边界

- 现有两个版本均为 JavaScript 与 p5.js 浏览器项目，使用 ml5.js HandPose 识别手部关键点，并使用 Web Audio API 合成声音。
- 没有大语言模型调用、自训练动作分类器或跨刷新保存关系的实现。
- 效用 AI 与优先级状态机都是有效的行为设计方法，但**不能描述为已经训练出会理解观众意图的机器学习角色**。
- Processing Java 与 JavaScript 是后续实现约束；现有 p5.js 源码不能直接视为可在 Processing Java 模式运行的代码。

## 7 交付物与验收方式

交付物：可运行的浏览器原型、全部源代码、运行说明、交互说明、简短演示视频。

最低验收：鼠标完成至少一轮核心互动；摄像头在目标设备上通过真实测试；动作到反馈有清晰因果关系；需要影响行为；三个主要成长环境可完整展示；声音可关闭；重启后可开始新一轮。
