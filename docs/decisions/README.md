## ADR-001 首轮用三工具路线而非纯自然手势
- **背景**：Brief V1 同时认可“抚摸 / 追逐 / 观察”的自主路线（原型 A）和 Feed / Play / Pet 的工具路线（原型 B）；首轮要验证的是“首次观众能否理解照料因果”。
- **可选项**：① 纯自然手势 + 自主生态；② 三工具 + 需要反馈；③ 自由对话。
- **决定**：② 为主路线，用自主休息和拒绝减少机械感。
- **代价**：观众需要切换工具，角色可能显得“听指令”。
- **推翻条件**：可用性测试中观众把工具当作任务清单，或研究证明自然手势在 30 s 内同样可学会。

## ADR-002 首轮用优先级状态机而非效用 AI
- **背景**：首轮行为数量少，重点是因果可读。
- **决定**：优先级状态机；效用 AI 作为“多需要竞争时”的扩展。
- **代价**：状态之间的取舍是硬编码顺序，难以表达“既饿又想玩”。
- **结果**：Brief V2 要求硬约束 + 效用的混合结构，由 ADR-006 取代。

## ADR-003 不做开放对话，不用生成式文本作为结语
- **背景**：两轮 brief 都把核心放在身体动作的可理解性上。
- **决定**：P0 只用固定模板和事件引用；生成式回顾列为 P2，且不得进入 Brain、不得改状态、不得编造互动，2 s 超时回退模板。
- **理由**：生成式文本不能证明本轮身体交互可靠，还会引入延迟、内容审核和“说出没发生过的事”的风险。

## ADR-004 区分“系统不确定”与“角色拒绝”
- **背景**：原型中丢手、跳点和角色不愿意都表现为“猫不理我”，观众会自责或误以为猫生气。
- **决定**：三层原因——系统没看清（`TRACKING_LOST`）、动作不确定（`INTENT_UNCERTAIN`）、角色边界（`NEED_REST / TOO_FULL / PRESSURE_HIGH / NOT_READY`）。前两者用光标与追踪提示，只有最后一层用身体动作表达；前两者**永远不影响关系数值**。
- **验证**：AT02（遮挡不扣信任）、AT09（unknown 期间不记忆）；可用性指标“原因理解 8/10”。

## ADR-005 工具从命令改为请求
- **背景**：原型 B 中 `tool !== 'PLAY'` 让工具成了免除压力处理的开关，PETTED 在手静止时总是胜出。
- **决定**：工具只表达观众正在**尝试**的互动类别，并对合法候选给 +0.25 请求加成；是否接受由硬约束和效用决定。新增第四个选项“Give space（等待/退后）”，让退后成为有效互动。
- **代价**：观众会遇到拒绝。对策：第一次拒绝同时告诉观众可尝试什么；拒绝不扣分。

## ADR-006 硬约束 + 效用选择
- **背景**：Brief V2 要求；同时需要回答“观察到了什么 / 角色需要什么 / 二者如何影响本次选择”。
- **决定**：会话冻结 → 输入有效性 → 压力与精力保护 → 不可中断短动作 → 效用选择；250 ms 决策，惯性 +0.10，切换门槛 0.15，最短保持 600 ms。每次决策留下候选分数、禁用原因和胜出理由。
- **理由**：安全边界交给规则（可证明），多需要取舍交给效用（有生命感），两者都可解释、可回放。

## ADR-007 有界统计适应而非在线学习
- **背景**：Brief V2 要求“至少 3 次有效事件后才可见变化、幅度受限、可重置”。
- **决定**：三个偏好（接触停留、玩耍节奏、靠近距离），中位数目标、0.8/0.2 平滑、10 s 限频、硬范围。适应不能改变质量门控、精力边界和拒识阈值。
- **理由**：短时展览中在线训练既无足够数据，也无法解释；统计更新可以用 `adaptation_on / off` 回放直接对比。
- **对外表述**：“I'm getting used to this rhythm”，而不是“已识别你的性格”。

## ADR-008 一份权威角色状态
- **背景**：Processing 展示端 + 浏览器感知端，若各自推算信任与成长会分叉。
- **决定**：本机 Node.js 运行唯一 CreatureCore；展示端只消费 30 Hz 快照并插值；命令用 commandId 去重。
- **当前实现**：`v2/core/` 是不依赖 DOM 与 p5 的纯模块，浏览器切片在同一进程中调用，测试在 Node 中运行同一份代码——这正是迁移到 Node 服务时要保持的边界。Processing 端尚未实现。

## ADR-009 信任不作为主屏数值奖励
- **背景**：原型 B 的需要条让观众以“刷满信任条”为目标，与策展主题“学习彼此的距离”冲突。
- **决定**：主屏用角色状态短语（Still watching you / Warming up / Comes to you），精确数值只在工作人员诊断面板（`D`）。
- **代价**：观众对进度的掌控感降低；对策是回顾中给出有事件依据的关系变化。
